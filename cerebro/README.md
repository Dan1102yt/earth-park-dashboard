# Cerebro de Earth Park

Aquí vive el conocimiento central del proyecto. Los agentes de IA leen estos archivos cada vez que trabajan, así que **un cambio aquí lo aplican todos**.

- `marca.md`: quiénes somos, audiencia, tono y reglas. Es el "sistema" de todos los agentes. Donde dice `{{PLANES}}`, la app pone sola los planes y precios de `src/configuracion/planesConfig.js`.
- `ganchos.md`: guía para escribir la primera frase o portada.
- `estructura-video.md`: las 4 partes obligatorias de cada video.
- `agentes.md`: el equipo de la Oficina IA.
- `decisiones.md`: registro de decisiones importantes y su porqué.

Reglas para editar:

1. Escribe en español de Colombia, con "tú".
2. No pongas claves, tokens ni datos financieros: este repositorio es público.
3. Después de editar, publica los cambios (`git push`). Los agentes usan la versión publicada.
